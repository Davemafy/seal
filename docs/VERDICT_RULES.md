# Verdict law

Every checked claim has exactly one verdict: MATCH, MISMATCH, or COULD_NOT_VERIFY. Positive and negative verdicts both require cited official evidence. No record is an abstention. Private juror identifiers and reporting dates need direct confirmation. A phone is contradicted only if represented as the official Jury Services number and the official numbers are available. A domain is contradicted only if represented as the official jury portal. Email addresses abstain without an exhaustive official rule.

A payment demand in a jury-related **call or text** conflicts with Riverside’s August 2026 warning. The same source does not establish a blanket rule for every paper notice. A generic paper payment request therefore abstains. The official Desert Region number appears as 760-342-6264 on several pages and 951-342-6264 in the countywide table. A claim involving either ambiguous number returns COULD_NOT_VERIFY with “Official sources currently disagree.” and both excerpts.

If OCR cannot confidently recover a field, do not send a guessed value to verification: “We couldn’t read this field confidently.” If the official page cannot be reached: “Official source could not be reached during this check.”
